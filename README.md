# Rebirth Reborn

Native macOS sequencer inspired by ReBirth, with two bass synthesizers, two drum machines and a compact rack interface.

**Apple Silicon · macOS 13+ · Swift / C++ · MIT**

This is an early development version. The sound engine is independently implemented, and the interface is drawn in code. All built-in drum sounds and filter patterns are generated by the project. No original application files, samples, songs, skins or extracted lookup tables are included. It does not claim sample-exact sound reproduction.

## Features

| Area | Functionality |
| --- | --- |
| Bass synthesizers | Two 303-inspired voices; saw/square, tune, cutoff, resonance, envelope modulation, decay, accent and slide. Optional 2× oversampling. |
| Drum machines | 808- and 909-inspired kits, with eleven voices each. Tune, decay, accents, strong hits and flam where applicable. |
| Sequencer | 32 patterns per device, A–D banks, 1–16 steps, shuffle, copy/paste/clear and pattern changes at bar boundaries. |
| Effects and mixer | Distortion, delay, linked compression, pattern-controlled filter, device levels, pan and sends. The filter has 55 generated patterns. |
| Song editor | Four pattern lanes, bar insertion/duplication/removal, seek, automation and MIDI-note editing. |
| Presets | Bass sounds, drumkits, effects, bass/drum patterns and full-rack snapshots. Search, save, rename, delete and JSON import/export. |
| MIDI | Live notes, CC control, persistent MIDI Learn, external 24-PPQN clock, transport messages and Song Position Pointer. |
| Recording and files | Record notes, controls and pattern changes; undo/redo; native JSON sessions; RBS compatibility; stereo WAV export. |

The 46 drum sample slots are synthesized from oscillators, envelopes and deterministic noise in memory at startup. No external sound library is required.

## Build and run

Requirements: an Apple Silicon Mac with macOS 13 or newer and Apple's Command Line Tools.

```sh
xcode-select --install  # if the Command Line Tools are not installed

git clone https://github.com/derpaile/rebirth-reborn.git
cd rebirth-reborn
bash RebirthReborn/build-app.sh
open "RebirthReborn/dist/Rebirth Reborn.app"
```

The script compiles the app, runs audio/model/effect checks, packages it in `RebirthReborn/dist/` and applies a local ad hoc signature. The app is not notarized. The finished app runs offline without developer tools.

The [macOS build workflow](https://github.com/derpaile/rebirth-reborn/actions/workflows/build.yml) runs the same checks on GitHub and uploads the packaged app as a build artifact.

## Controls

| Action | Input |
| --- | --- |
| Play / stop | Space |
| Adjust a knob or fader | Drag, mouse wheel or arrow keys |
| Fine adjustment | Hold Shift |
| Reset a control | Double-click |
| Enter tempo, loop values or bass step | Double-click the number |
| Undo / redo | ⌘Z / ⌘⇧Z |
| Song Editor | ⌘E |
| Presets | ⌘⇧P, or right-click a device's pattern area |
| Zoom | View / Ansicht, 100–200%, constrained by the available display |

The rack maintains its 592 × 510 logical proportions. Background plates are cached at 4× resolution; controls and indicators update separately. The window accounts for the title bar when scaling.

## Sessions, presets and soundpacks

Use native JSON sessions to retain all settings, recorded MIDI notes and embedded user-created soundpacks. Presets are stored in:

```text
~/Library/Application Support/Rebirth Reborn Community/Presets/library.json
```

Factory presets are read-only; save a copy to edit one. Bass presets can target either bass voice. Drumkits distinguish the two drum machines. A soundpack's sample bank applies to the whole rack, so replacing it affects both drum machines.

User-created `.rbrpack` files can provide AIFF samples and optional JPEG/PNG skins. Omitted sample slots retain the generated defaults. See [soundpack format](docs/soundpacks.md).

The RBS reader/writer provides file-format compatibility. RBS does not contain the remake's sound engine or samples, and cannot store the native MIDI-note extension. Incompatible saves are rejected to prevent data loss. Original encrypted RBM packages are not supported by the public build.

## MIDI

Enable MIDI in **MIDI → Clock und MIDI-Learn**.

- Bass voices use channels **1 and 2**; drums use **10 and 11** with GM-style note mappings.
- Bass CCs **20–25** control tune/cutoff/resonance/env mod/decay/accent; **26** selects waveform, **7** controls level and **10** controls pan.
- For MIDI Learn, select a target or the last moved control, click **Lernen** and send a CC. Assignments are stored locally.
- External clock accepts **24 pulses per quarter note**, automatic or explicit source selection, Start/Continue/Stop and Song Position Pointer.
- Recording captures notes, controls and pattern changes. Stop closes held notes and creates one undo step.

External clock follows incoming pulses; sample-exact synchronization with an external host is not guaranteed.

## Export and verification

WAV export renders a pattern loop or the full song, including the effect tail, as stereo Float32 at 44.1 kHz. The comparison tool aligns two matching stereo files within ±2048 samples and reports error, correlation and length.

The build checks synthesized samples, all 22 drum voices, bass controls and oversampling, deterministic and bounded audio, MIDI decoding/clock, presets/history, JSON/RBS/soundpack round-trips, WAV export and all 55 filter patterns in both modes at control extremes.

Additional app checks can be run separately:

```sh
"RebirthReborn/dist/Rebirth Reborn.app/Contents/MacOS/Rebirth" --feature-check
"RebirthReborn/dist/Rebirth Reborn.app/Contents/MacOS/Rebirth" --ui-check
```

Each opens a test instance and exits after its checks. The UI check also writes `/tmp/rebirth-reborn-ui-check.png`.
